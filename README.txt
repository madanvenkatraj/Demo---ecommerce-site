NOVA MARKET — RESPONSIVE E-COMMERCE DEMO

Files
- index.html: Complete single-file website with embedded HTML, CSS, and JavaScript.

How to run
1. Extract the ZIP file.
2. Open index.html in a current browser (Chrome, Edge, Firefox, or Safari).
3. An internet connection is recommended because product photography is loaded from Unsplash.

Included features
- Responsive layout for desktop, tablet, and mobile.
- Product catalog with category filtering, keyword search, and sorting.
- Wishlist toggles and wishlist-only view.
- Product quick-view dialog.
- Shopping cart drawer with quantity controls, remove action, subtotal, shipping, and total.
- Newsletter form interaction and toast notifications.
- Mobile navigation and keyboard Escape close behavior.

Important
This is a front-end demo. Cart state is kept in memory and resets on page reload. Checkout does not accept payments or create real orders. Product names, prices, shipping policies, and contact details are sample content. Product images are remotely hosted by Unsplash.
